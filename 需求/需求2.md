# 项目：2027 年每日一页日历 · HTML 视觉设计

## 一、整体调性
日式极简 × 杂志编辑感 × 温柔治愈。
不是"信息排版"，而是"每日一件小作品"。
每翻一页，像翻开一本诗集的一页。

关键词：留白、克制、层次、肌理、呼吸感、印刷品质感


## 二、版面结构（横版）
画面分四个层次，从底到顶：

Layer 1 — 背景层
- 生活照片，透明度 15%~25%，铺满整页
- 叠加米白遮罩（透明度 30%），压暗照片保证可读
- 再叠加极淡网格肌理（5mm 间距，透明度 3%）

Layer 2 — 装饰层
- 极细线条收边（顶部、底部各一条，0.5px）
- 装饰线条组（3~5 条粗细不一的短线，错落排布）
- 圆点阵列（3×3，其中一点为强调色）
- 月度进度条（31 个刻度，当前日期红点标记）

Layer 3 — 内容层
- 顶部：月份（中英双排）+ 年份，左对齐 / 右对齐
- 左侧：竖排日期信息带（页边注感，字号 6pt，字距极大）
- 中央：超大日期数字（主视觉）
- 底部：星期（中英）+ 每日话语 + 月度进度

Layer 4 — 点缀层
- 印章 / 落款（朱红小方章，微旋转 -3°）
- 小色块（4mm × 4mm，用于视觉锚点）


## 三、主视觉：日期数字
不是简单"放大数字"，而是参与构图。

可选手法（按日期轮换）：
1. 出血 — 数字顶到画面边缘，被裁切，制造张力
2. 负空间 — 背景图从数字形状中透出（background-clip: text）
3. 双层叠印 — 实心数字 + 偏移 1.5mm 的描边数字，像套印错位
4. 描边空心 — 只有轮廓，内部透出背景

字号：160~200pt，衬线体，笔画有粗细对比。
颜色：平日墨色，周末朱红。


## 四、素材系统

### 4.1 生活照片（data/img/）
处理手法：低透明度铺底（唯一手法）

参数：
- 透明度 15%~25%
- 铺满整页，background-size: cover，居中裁切
- 叠加米白遮罩（透明度 30%）
- 统一色调：低饱和 −20%~30%，色温偏暖，对比度略降

层次：
照片（20%）→ 米白遮罩（30%）→ 网格肌理（3%）→ 文字插画

效果：
隐约看到照片影子，像记忆的底色，
但第一眼看到的是日期和排版。

分组规则：
- 按季节：春 / 夏 / 秋 / 冬
- 按情绪：治愈 / 励志 / 解压 / 温柔
- 特殊日期用专属照片
- 不随机乱配，按主题映射

### 4.2 每日话语（data/Info/info.json / data/quotes2027.js）
- 从配置文件读取
- 按类别分组：励志 / 夸夸 / 调侃 / 节日
- 三类各 122 条，按日期序号轮换，全年 365 天零重复
- 特殊日期（节日）优先覆盖默认


## 五、色彩系统
底色    #f4f1ea  米白（主背景、遮罩）
主色    #2a2620  墨色（文字、数字）
点缀    #b03a2e  朱红（印章、周末、强调）
辅助灰  #8a8276  中灰（次要文字）
辅助灰  #c8c2b6  浅灰（线条、肌理）

周末 / 节日：主色切换为朱红
特殊节日：可引入金色 #c8aa6e


## 六、字体系统
数字主字体   Playfair Display 900（衬线、优雅、有张力）
中文标题     Noto Serif SC 400/600（宋体、书卷气）
英文辅助     Inter 200/300（无衬线、极细、现代）
字距        标题类字距拉宽（4~8px），正文正常

原则：字体可艺术，但必须清晰可读。
最小字号不低于 6pt，对比度足够。

## 八、设计原则
1. 留白即设计 — 空白是呼吸，不是浪费
2. 不对称 — 拒绝居中对称，用错位制造张力
3. 层次感 — 前景、中景、背景分明
4. 一个锚点 — 每页只有一个视觉焦点
5. 印刷感 — 像真实印刷品，不是网页截图
6. 每日不同 — 靠数字手法轮换制造节奏


## 九、技术约束
- 纯 HTML + CSS + JS，无框架依赖
- 可导出精确尺寸 PDF（@page 控制）
- 打印时背景色和图片正常输出
- 所有尺寸用 mm，字体除外


## 十、不要出现的
- 居中对称的平庸排版
- 信息均匀分布，没有焦点
- 纯色大色块，没有肌理
- 照片只是"垫底"，不参与氛围营造
- 数字只是放大，不参与设计
- 超过 4 种主色
- 廉价模板感、素材站感
